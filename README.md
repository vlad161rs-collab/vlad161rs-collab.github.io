# 🎨 Современное Портфолио

Современный и стильный сайт-портфолио с возможностью добавления изображений и описаний к проектам.

## ✨ Особенности

- 🎯 **Современный дизайн** - Градиенты, анимации, glassmorphism эффекты
- 📱 **Адаптивный** - Отлично работает на всех устройствах
- 🖼️ **Галерея проектов** - Красивая сетка с карточками проектов
- 🔐 **Система авторизации** - Только администратор может добавлять/редактировать/удалять проекты
- 👁️ **Публичный просмотр** - Все пользователи могут просматривать проекты
- ➕ **Добавление проектов** - Простое добавление изображений и описаний (только для авторизованных)
- ✏️ **Редактирование** - Возможность редактировать существующие проекты (только для авторизованных)
- 🗑️ **Удаление** - Удаление ненужных проектов (только для авторизованных)
- 💾 **Локальное хранение** - Все данные сохраняются в браузере
- 🎭 **Анимации** - Плавные переходы и эффекты при наведении

## 🚀 Быстрый старт

### Локальный запуск

1. Откройте `index.html` в браузере

2. Для добавления/редактирования проектов нажмите "🔐 Войти" и введите пароль администратора

3. **Пароль по умолчанию:** `ADMIN_PASSWORD_REMOVED` (измените его в файле `script.js`, строка `const ADMIN_PASSWORD`)

### Деплой на GitHub Pages (vlad161rs.github.io)

1. Создайте репозиторий `vlad161rs.github.io` на GitHub
2. Загрузите файлы в репозиторий
3. Включите GitHub Pages в настройках репозитория (Settings → Pages → Source: main)
4. Сайт будет доступен по адресу: **https://vlad161rs.github.io**

## 🎨 Использование

### 🔐 Авторизация

1. Нажмите кнопку "🔐 Войти" в правом верхнем углу
2. Введите пароль администратора (по умолчанию: `ADMIN_PASSWORD_REMOVED`)
3. После успешного входа вы получите доступ к функциям редактирования
4. Сессия сохраняется на 24 часа
5. Для выхода нажмите "🔓 Выйти"

**⚠️ Важно:** Измените пароль по умолчанию в файле `script.js`:
```javascript
const ADMIN_PASSWORD = 'ваш_новый_пароль';
```

### Добавление проекта (только для авторизованных)

1. Войдите в систему
2. Нажмите кнопку "Добавить проект"
3. Выберите изображение
4. Введите название проекта
5. Добавьте описание
6. (Опционально) Добавьте ссылку на проект
7. Нажмите "Сохранить"

### Редактирование проекта (только для авторизованных)

1. Войдите в систему
2. Нажмите "Редактировать" на карточке проекта
3. Внесите изменения
4. Сохраните

### Просмотр проекта (доступно всем)

Нажмите "Просмотр" на карточке проекта для просмотра в полноэкранном режиме. Эта функция доступна всем пользователям без авторизации.
